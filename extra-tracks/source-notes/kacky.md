## Selection and validation

Upstream has 35 numbered throwback `.track` files. Three (`42.track`, `45.track`, and `46.track`) are empty and were excluded. Track #58 was excluded because its metadata `author` value, `No Cutting this one!`, does not reliably identify a creator. The 31 imported files are nonempty, start with `PolyTrack2`, and are each below 524288 characters. All 31 pass the game's two-stage decode format, contain nonempty track data, and have embedded names and authors matching the catalog. This is structural playability validation, not a manually completed race.

SHA-256 is over the trimmed UTF-8 track code. The imported codes are unique within this set and have no matching code SHA-256 among the fork's existing `tracks/**/*.track` files.
