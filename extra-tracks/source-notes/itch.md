# itch.io PolyTrack community source note

Twenty individually selected exports came from [Kodub's public track-sharing thread](https://itch.io/t/2912863/share-your-tracks-here). The catalog retains each post permalink, displayed forum author, embedded track author and title, and post/track dates where available. Forum likes and reply counts are snapshots of visible post activity, not play counts. Missing vote totals remain unknown rather than zero.

Four candidates were excluded during curation: three repetitive or weakly described short entries and one with unsuitable embedded credit. Every included code passed bounded format checks and loaded in the local PolyTrack 0.6.3 game parser with a valid start. Track IDs and preview PNGs were generated from that native parser; no itch.io artwork was copied. Full codes load only when a player chooses a track, while catalog thumbnails load lazily. Neither is fetched on initial game startup.

The source is labeled `itch.io community` in Extra Tracks. This collection is not affiliated with or endorsed by itch.io or Kodub. Attribution corrections and removal requests can be handled through the game's track report flow.
