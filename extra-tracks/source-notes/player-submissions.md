# Player-submitted tracks

The project owner supplied the complete codes and the submission records for Ithan and Canyon of Death on 2026-09-27. Both submission records marked redistribution permission granted. The native PolyTrack 0.6.3 decoder confirmed each track ID and generated the thumbnails locally. The bounded verifier preflight counted 4,088 and 4,533 parts respectively, both below its 20,000-part default limit. This confirms structural compatibility, not that a human completed either route.

The catalog credits the authors embedded in the codes: Selver for Ithan and Lifeless_Sweat (with crown emoji around the name) for Canyon of Death. The submission records had the same submitting account but different author strings. Account identifiers are not published in the catalog. The submission timestamp is shown separately from the optional code modification timestamp; neither is inferred from the other.

The user-provided difficulty, description and tags remain editorial metadata. Ithan has no embedded modification date. Canyon of Death includes a modification date of 2026-09-18. Its source link is the Discord URL supplied in the submission record.
