## Other Wording

- "2 newer updates" becomes "2 updates since you last checked." The count remains hidden for one update or an unknown previous release.
- "Snapshot package" becomes "Snapshot" in ranking and track status.
- "Local recalculation" becomes "local estimates." It appears only when a local PB changes the displayed estimate.
- Update notices resume on menu changes and catch up on focus after the existing cooldown. Reloads still require an explicit click and a safe main menu.
