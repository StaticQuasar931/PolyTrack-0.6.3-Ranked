# PolyTrack 0.6.3 compatibility

This edition uses the PolyTrack 0.6.3 game with Community Ranked additions.
This page describes compatibility, not a migration or deployment procedure.

- Existing player accounts and saved personal bests are retained.
- `polytrack_062_patch.js` and `0.6.2_*` database names are compatibility identifiers. They do not describe the current game version.
- Official, community and Extra Tracks keep their own eligibility rules. Legacy tracks can retain historical results even when absent from the current menu.
- Replay verification uses reviewed engine and track identities. A player-supplied verification flag is not proof.
- Events and ordinary track runs share eligible finishes only when submitted during the matching active event period.

For current features and controls, see the main README and in-game help.
